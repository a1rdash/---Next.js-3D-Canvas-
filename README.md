# game meha — 3D-версия

## Запуск
```bash
pnpm install     # подтянет three и @types/three (добавлены в package.json)
pnpm dev
```

## Что нового
- `components/game/car3d/build-car.ts` — процедурная 3D-машина (7 типов кузова), цвет по названию краски,
  колёса со спицами, фары/стопы, тюнинг виден на модели:
  - Визуал 1: спойлер · 2: обвес (пороги, сплиттер, диффузор) · 3: полосы, воздухозаборник, неон под днищем
  - Мотор 1/2/3: один выхлоп → два → два с пламенем
  - Подвеска: машина садится ниже, появляется развал
  - Новая деталь «выскакивает» с анимацией, камера сама подлетает к ней
- `components/game/car3d/car-viewer.tsx` — студия: вращение пальцем/мышью, зум, кнопки ракурсов,
  плавные перелёты камеры, заезд машины на подиум, луч-сканер при осмотре зоны.
  Подключён в `inspection-view.tsx` (осмотр перед покупкой) и `car-workshop.tsx` (после покупки).
- `components/game/car3d/drive-engine.ts` + `test-drive.tsx` — тест-драйв в 3D: город, фонари, трафик,
  камера погони с пролётом на старте, тряска при ударах, звук мотора, спидометр.
  Погода и время суток берутся из игры: дождь (капли, брызги из-под колёс, мокрый асфальт, молнии),
  туман, утро/день/вечер/ночь (звёзды, фары с конусами света).
- `weather-overlay.tsx` — дождь на canvas со всплесками и молниями, многослойный туман.

## Обновление v5

- **Тест-драйв:** при каждом запуске случайный пресет «время суток × погода» (`ENV_PRESETS` в `test-drive.tsx`: утро/день/вечер/ночь × ясно/дождь/снег). Применяется к небу, освещению, фарам и частицам (дождь, брызги, снег, дымка).
- **Пешеходы на зебре** (`drive-engine.ts`): выходят на переход строго на красный для машин, на зелёный не выходят, а вышедшие ускоряются и заканчивают переход; машины ждут пешеходов, а игрок получает нарушение, если не уступил.
- **Модели машин:** кузов «ваяется» (сужение к носу и корме, скруглённые углы, завал боков, узкая кабина), скруглённые бамперы, арки, фары, стойки и крыша.
- **Превью 3D:** студия с циклорамой, софтбоксами и световыми панелями вместо пустоты; кнопки ракурсов и подсказки вынесены в отдельные полосы, текст осмотра и название машины больше не перекрывают модель.

## Обновление v6

- **Салон:** сиденья, руль и приборка масштабируются по высоте крыши (`headroom` в `build-car.ts`) и не торчат из кузова.
- **Пешеходы:** наезд = триггер-зона по габариту машины → импульс, отлёт с кувырками, падение и «лежание» (`hitPed`, `updateFlyers` в `drive-engine.ts`), штраф 30 000 ₽ (`DRIVE_FINE` в редьюсере) и красное предупреждение на экране; пешеход через время появляется заново.
- **`lib/shaders/car-paint.ts`:** PBR-шейдер автокраски для Three.js (`createCarPaintMaterial`, `setCarPaintSun`): clear coat, металлические блёстки, затемнение на краях, RNM-смешивание нормалей и микро-нормаль шагрени. В игру по умолчанию не подключён.
- **`lib/physics/car-controller.ts`:** фреймворк-независимый контроллер автомобиля (Пасейка, рейкаст-подвеска со стабилизаторами, двигатель, сцепление, коробка, дифференциал, перенос веса). В игру по умолчанию не подключён (игра использует аркадную модель).

## Исправление v7

- `weather-overlay.tsx`: ошибка `ellipse ... radius is negative` в дожде. Причина: на первом кадре таймстамп `requestAnimationFrame` мог быть меньше `performance.now()`, из-за чего `dt` становился отрицательным и радиус брызг уходил в минус. Теперь `dt` не меньше 0 (дождь и снег), а радиус эллипса ограничен снизу.

## Обновление v8

1. **Обучение** (`components/game/tutorial.tsx`, `lib/settings.tsx`): гайд из 5 шагов при первом запуске (цель, вкладки, управление со схемой кнопок, правила дороги, лицензия). Есть «Пропустить», пересмотр в Профиль → Настройки → «Показать обучение снова». В первом тест-драйве показывается короткая подсказка по кнопкам.
2. **Звук при сворачивании** (`lib/audio-focus.ts`): все `AudioContext` (музыка и мотор) регистрируются; `visibilitychange`, `blur`, `pagehide` ставят их на паузу, `visibilitychange`, `focus`, `pageshow` возобновляют. Ручное «без звука» не затрагивается. Есть помощник для HTML5-аудио.
3. **Управление** (`test-drive.tsx`, `drive-engine.ts`): кнопки ГАЗ, СТОП, ◀, ▶ работают по удержанию и независимо (pointer capture, мультитач); клавиатура учитывает каждую клавишу отдельно. Свайп по холсту отслеживается по `pointerId` и не перехватывает касания кнопок.
4. **Разгон:** при зажатом газе ускорение плавно затухает к `maxV` (`a ~ 1 - (v/maxV)^2.4`), при отпускании — выбег с трением и сопротивлением воздуха; тормоз — удержание.
5. **Графика** (`lib/settings.tsx`, GRAPHICS): Низкая (без теней, частиц и постобработки, DPI 0.8, 30 FPS), Средняя (простые тени, половина частиц), Высокая (мягкие тени 2048, все частицы, DPI до 2, без лимита FPS). Применяется в тест-драйве, 3D-фонах, превью машины и погодных эффектах.
6. **Отступы:** убрано двойное применение `safe-area-inset-top` в главном меню (верхние элементы выше, но под строкой состояния); в тест-драйве HUD и кнопки компактнее и используют безопасные зоны со всех сторон (в том числе при повороте интерфейса на 90°).
7. **Нотариус:** варианты ответа перемешиваются, верный ответ стоит на разных позициях (минимум на трёх разных в одном экзамене).
